# Sistema de Cadastro de Alunos

## Nome do aluno
Carolline Engler

## Nome da disciplina
Git e GitHub

## Objetivo do projeto
Desenvolver um pequeno sistema de cadastro de alunos utilizando Git e GitHub para praticar controle de versões e organização do desenvolvimento.

## Linguagem utilizada
C

## Descrição do programa
O programa permite cadastrar informações básicas de um aluno, como nome, idade e nota, e exibir os dados cadastrados.

## Como executar o programa
O programa pode ser executado utilizando um compilador da linguagem C, como o GCC. Basta compilar o arquivo main.c e executar o programa.
